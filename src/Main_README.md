# Main Program

## Overview
The `Main` class serves as the entry point for the Solar System Project application. It initializes and launches the Java Swing GUI application for visualizing and controlling a solar system simulation.

## Purpose
- Bootstraps the application
- Sets up the main application window
- Initializes the GUI components (ControlPanel and AnimationPanel)
- Manages the overall application lifecycle

## Components Used
- **ControlPanel**: Provides user controls for the simulation
- **AnimationPanel**: Displays the animated solar system visualization

## Usage
Run the Main class as a Java application to start the Solar System simulator.

## Key Features
- Interactive GUI interface
- Real-time animation display
- Control panel for user interaction
